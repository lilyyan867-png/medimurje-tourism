TASTE · MEDIMURJE

葡萄酒之路 · 一方风土，一脉葡香

梅吉穆列是克罗地亚最北端的迷你葡萄酒产区，也是全球单位面积获奖最多的产区之一。
从普希佩尔白葡萄酒到兹林斯基城堡的宫廷食谱，每一口都是中欧与地中海的交融。

沿丘陵，寻访百年家族酒窖

( Signature )

普希佩尔

梅吉穆列特有的白葡萄品种，被誉为产区的专属名片。经典款口感轻盈，带有清新柑橘果香，易饮百搭；尊享款陈酿时间更长，酒体醇厚，风味层次丰富——从入门到进阶，都能找到属于你的那一杯。

品种 长相思 · 绿维特纳 · 灰皮诺 · 莱茵雷司令 · 黄麝香

( Festival )

葡萄酒节

Urbanovo

每年 5 月中旬在什特里戈瓦举办，是普希佩尔葡萄酒的年度国际盛会。一年仅一次的酒窖全开，沿线百年家族酒庄同步开放地下酒窖；国际专家品鉴会、酒窖开放日、主题晚宴与现场音乐会接连上演，是深度体验产区文化的最佳时机。

时间 5 月中下旬 · 为期 3 天 · 什特里戈瓦镇

( 01 )

圣马丁温泉度假村

Terme Sveti Martin

坐落于葡萄酒之路核心地带，是欧洲首家葡萄酒主题康养度假村。周边配套百栋高标准乡村别墅，泡葡萄酒精油温泉，眺望连绵葡萄园——这是葡萄酒产区才有的专属享受。

地点 葡萄酒之路核心地带
( 02 )

Hazić 葡萄酒营地

Jurovčak

住在酒庄里，清晨醒来就是葡萄园，傍晚在露台小酌本地酒款。小众特色住宿选择，远离城市喧嚣，体验最原汁原味的酒乡慢生活。

地点 Jurovčak
( 03 )

马德尔金布雷格观景台

Mađerkin Breg

站在这里，可以俯瞰什特里戈瓦全景，一片连着一片的葡萄园在丘陵上铺展，是拍摄日落的最佳机位。晴天时，视线可以越过葡萄园直达远处的平原与河流。

( 04 )

圣杰罗姆 · 圣乔治教堂

Churches of Medimurje

沿葡萄酒之路散落着多座中世纪教堂，钟楼、壁画与老石墙，感受最纯粹的中欧乡村建筑风貌。圣杰罗姆、圣乔治等教堂至今仍在本地社区中扮演重要角色。

梅吉穆列美食志

( Cuisine )

梅吉穆列的饮食文化融合了维也纳、布达佩斯、威尼斯三地风味，17 世纪兹林斯基城堡的宫廷食谱流传至今。当地美食曾入选联合国世界旅游组织全球美食旅游精选网络，斩获欧洲卓越目的地（EDEN）大奖。
